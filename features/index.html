Features

Everything below the game, nothing inside it.

Each feature works on the Windows display layer or in our own window. That is the whole design constraint, and it is what keeps profiles portable and reversibility honest.

Install

  1. Download the portable x64 executable from the release page.
  2. Run it on Windows 10 or 11. No installer and no driver.
  3. Pick a display, load a preset or tune the sliders yourself.

What it never does

  • No DLL injection into a game process.
  • No game memory reads and no game file changes.
  • No anti-cheat bypass, kernel driver or hidden service.
  • No keystroke logging — hotkeys are registered with the OS.

Reference

Feature by feature.

What each tool does, the exact boundary it works inside, and how to get back to where you started.

01

Per-monitor color

Tune brightness, contrast, saturation, temperature and gamma for each display independently. Your main monitor and your side panel finally stop arguing.

What it does

  • Separate profiles keyed to the display identifier, so moving a window between monitors does not drag the wrong look with it.
  • Fine-grained white balance and per-channel control for panels that leave the factory a little too warm or a little too cold.
  • Night and day variants that swap on a schedule or on a hotkey you choose.

Boundary

Applies at the Windows display layer. HDR and OS night-light modes can override parts of the pipeline, and results depend on the panel and its calibration.

02

Game profiles

Bind a look to a game executable. Launch the title, get the profile you saved for it — no launcher hooks, no process patching.

What it does

  • Match by executable name or by a folder you pick, then attach a color profile and overlay layout.
  • Switch profiles from a hotkey while a game is running, even in windowed or borderless mode.
  • Export and import presets as shareable text codes for a second machine.

Boundary

Matching uses the executable name and path. VYTRIX does not read game memory or inspect the game's rendering state.

03

Crosshair overlay

A clean reticle drawn in our own transparent window. Shapes, sizes, colors and offsets, with per-game auto-show.

What it does

  • Dot, cross, bracket and circle styles with independent gap, thickness and opacity controls.
  • Center point or custom offset for games that place the aim point away from the screen middle.
  • Auto-show rules tied to the same game profiles you already use for color.

Boundary

The overlay is drawn on top of the game; it does not read the game. Some fullscreen-exclusive titles require borderless windowed mode.

04

Optimizer

A touch-to-reveal Optimizer panel that runs the full Platinum+ v9.5 Windows profile. It reads your Windows build first, applies only the entries that fit it, and saves every previous value for a one-click undo.

What it does

  • Open the Optimizer card to see attribution first: not ours, ported from Platinum+ Optimizer v9.5 by @STEFANO83223 and @Aledect on SourceForge. Upstream updates are not ours.
  • Windows 10 and Windows 11 are detected from ProductName, DisplayVersion, CurrentBuild and UBR in the registry. Windows 11-only entries such as the Copilot button are skipped on Windows 10.
  • The full profile covers over a hundred fixed registry writes plus netsh TCP tuning, bcdedit boot flags and a dedicated VYTRIX high-performance power plan, grouped by network, memory, graphics, storage, power, services and privacy.
  • Run everything or work group by group. Each applied setting records its prior value in the local vault, and Restore replays it — including the original power plan.

Boundary

Ported from a community Windows tuning script; the settings are real system changes, so the previous value is captured before each one and every entry is reversible. Defender, firewall and Update availability are never disabled.

05

Performance monitor

Frame timing and system load in a small overlay, sourced from standard Windows counters and driver telemetry.

What it does

  • Frame time, CPU and GPU utilization with configurable refresh rate and smoothing.
  • Optional compact overlay with just the numbers you care about.
  • Session logs written locally so you can compare a before and after tweak.

Boundary

Reads system counters, not game memory. Which counters exist depends on your GPU driver and Windows build.

06

Phone control

A small companion page on your phone for switching profiles and nudging brightness without leaving the couch.

What it does

  • Explicit pairing between the desktop app and the phone on the same local network.
  • Quick profile switching, a brightness slider and a readout of the active display.
  • No cloud relay and no account on the phone — the session lives on your LAN.

Boundary

Requires the desktop app to be running and both devices on the same network. Cellular data and remote relay are not supported.

07

Utility zoom

A real full-screen magnifier through the documented Windows Magnification API. Pick a level, then use Toggle or Hold on a bind you choose.

What it does

  • Toggle activates on a single bind press and stays until you press again or release it.
  • Hold magnifies only while the bind is held, then restores the display on release.
  • Level is selectable from 1.0x to 8.0x, with live status reported back into the app.

Boundary

Uses the Windows full-screen transform. Exclusive-fullscreen or protected-content windows can block magnification; the status row reports API rejection.

08

SnapTap

A bundled keyboard snap-tap utility in the misc category. Universal mode runs in every window. Source, prebuilt binary, config and profiles ship with VYTRIX.

What it does

  • Launch the included binary and pick a profile from the tray, then hold opposing movement keys.
  • Universal mode is on by default: the transform is active in every window with one global jitter range and no title gating.
  • The full source, config keys, five profiles and MIT license are included for inspection and rebuild.

Boundary

VYTRIX does not read keyboard input, inject code, read game memory or modify game files. Set universal=0 for the legacy detection mode.

The constraint

Why no injection is a feature.

A tool that lives outside the game does not need to keep up with anti-cheat updates, does not break when a renderer changes, and can be removed without leaving anything behind.
