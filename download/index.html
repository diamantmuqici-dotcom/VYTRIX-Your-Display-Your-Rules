Portable build, no gate.

VYTRIX is fully free and open source. Grab the published Windows x64 portable executable directly from the public GitHub release — no account, no gate, no hidden payload.

Windows x64 · portable

VYTRIX-x64-portable.exe

A single self-contained executable. Unzip nothing, install nothing, leave no service behind. Run the executable and tune your displays. Every color change stays in your graphics driver until you close the app or hit reset.

Verify the download

Each release publishes a .sha256 sidecar next to the executable. Run certutil -hashfile VYTRIX-x64-portable.exe SHA256 and compare the output against it before launching.

Requirements

  • Windows 10 or Windows 11, 64-bit
  • WebView2 runtime (preinstalled on Windows 11)
  • No kernel driver and no background service
  • Local user account; no cloud sign-in needed to tune displays

Built from source, in the open

Every line is in the public repository under the MIT license. CI rebuilds and tests the workspace on every push, and each release is assembled by the same workflow.
