How it works

A catalog you can audit.

The website, the desktop app and the generator read the same source data. Nothing here is a hand-maintained marketing list.

Detection is declared, not guessed at runtime

Each entry lists its executable names, process names and launcher signals. Confidence is written down as verified, partial or manual so you know how the match is made.

A profile describes capabilities, not cheats

Color profiles, display profiles, monitoring and restoration are bounded declarations. Crosshair and overlay support is marked supported, restricted or unknown per title.

The boundary is the display layer

VYTRIX changes Windows display state in your own session. It does not modify game files, read game memory, inject code or bypass anti-cheat. Those are listed as unsupported on every entry.
